# 09 段階的実装計画

## 進め方の約束

- 1段階ずつ作り、**既存のテストが全部通る**ことと、その段階のテストが通ることを確かめてから次へ進む
- 将来の機能を先回りして作らない。インターフェースだけ用意し、中身は必要になった段階で作る
- 人に届くこと（ルームに声を流す・チャットに書く・外部へ送る）は、後の段階で、本人の了解をとってから
- 実際の AI API を使う確認は、費用がかかるので本人の了解をとってから流す（`--live`）
- 各段階の終わりに、開発ログに経緯を書き、本人の確認をもらってからコミットする

## 全体の順番

```mermaid

  S0["S0 合意"] --> S1["S1 APIキーの<br/>入力と保存"]
  S1 --> S2["S2 音声サービス<br/>（止められる再生）"]
  S2 --> S3["S3 エージェントの骨組み<br/>（模擬AI・手入力）"]
  S3 --> S4["S4 実際のAI<br/>人格・費用"]
  S4 --> S5["S5 GRAVITYの<br/>チャットとつなぐ"]
  S5 --> S5b["S5b チャットで<br/>会話する"]
  S5 --> S6["S6 声を聞く<br/>（検知・文字起こし）"]

  S7 --> S10["S10 声紋・VOICEPEAK・<br/>2つ目の提供元（要判断）"]
```
